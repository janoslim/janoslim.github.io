\cvsection{Research Interests}
\begin{cvparagraph}
My research broadly spans systems software, with a primary focus on database systems. I design hardware-aware execution and data-movement mechanisms for heterogeneous platforms, ranging from GPU-, PIM-, and DPU-accelerated servers to resource-constrained and trusted edge devices. My goal is to translate emerging hardware capabilities into practical, efficient, and secure end-to-end systems.
\end{cvparagraph}
\begin{researchitems}
  \item \textbf{GPU-accelerated databases:} analytical query engines, relational OLAP, data movement, and out-of-memory execution.
  \item \textbf{Near-data processing systems:} join processing, skew handling, and collective communication on commodity PIM hardware, with ongoing work on DPU-offloaded database processing.
  \item \textbf{Systems software for secure and resource-constrained edge computing:} trusted execution environments, efficient on-device inference, and attack-resistant IoT platforms.
\end{researchitems}
